# 孙学体技法库

这份文件不是《我的女友景甜》的逐段赏析，而是一套可迁移的写作装置。使用时先看用户素材，再选择技法。不要为了像原文而复制"海、空房间、胶带、指甲、五千万"这些母题；真正要迁移的是冷叙事、数字、流程、物件、系统和反体面判断。

孙学体的关键不是"写得像孙宇晨"，而是制造一种效果：叙述者掌握很多资源，却在最要紧的地方无能为力；文本拥有大量事实，却拒绝给读者一个完整解释；钱、技术和流程都在场，人反而像缺席了。

## 一、反差开场

**作用**：三句话内建立重量级矛盾，让读者直接进入冲突。

**结构**：

1. 一个极小、极轻、极便宜、极私密的事实。
2. 一个极大、极重、极昂贵、极公共的事实。
3. 第三句把两者扣到同一个人或同一件事上。

**可迁移句法**：

- 一张工牌的成本，十二块。
- 一间办公室的月租，二十七万。
- 我第一次觉得自己被公司承认，是保安让我从访客通道进去的时候。

**适用题材**：

- 创业：早期便宜物件 vs 后来巨大估值。
- 财富：小额犹豫 vs 大额决策。
- 情感：一句没发出的消息 vs 多年后仍在运行的提醒。
- 技术：一次 API 返回 vs 一笔真实交易。

**误区**：

- 不要写"这形成了鲜明对比"。
- 不要为了对称编造数字。
- 不要让开头解释背景。背景放到第二节。

## 二、白描不是少写，是只写可观察物

**作用**：把情绪从作者嘴里拿走，交给动作、物件、时间和流程。

白描只写四类东西：

- 物理动作：拿起、放下、扣住、签字、转账、删掉。
- 可计量事实：金额、人数、页数、温度、时间、距离。
- 现场流程：安检、报销、会议签到、医院抽血、系统审核、酒店打扫。
- 外部反应：助理怎么做，服务员怎么问，路人有没有停下。

**可迁移句法**：

- 她把文件翻到最后一页，没有看条款，只看签名栏。
- 系统提示需要二次验证。我输了两次验证码。
- 会议室里一共十三把椅子，只有十二个人坐下。
- 他把礼品袋放在脚边，结束的时候忘了拿。

**误区**：

- "我很难过"要改成"我把手机屏幕朝下放了三次"。
- "气氛很尴尬"要改成"服务员进来换水，换到一半退了出去"。
- "他很有钱"要改成钱怎样进入流程：谁审批，几张卡，几分钟到账，账单上叫什么科目。

## 三、短句是节拍，场景必须厚

**作用**：用短句制造敲击感，但不牺牲场景密度。

短句不等于写得少。一个关键场景可以由十几个短段落组成。每段只推进一个动作、一个回答、一个停顿。读者不是被解释带着走，而是被节拍一步一步压进去。

**节奏模型**：

- 短句进入。
- 两三句对话。
- 一个长一点的动作链。
- 一个数字落下。
- 一句沉默。
- 一个动作收尾。

**可迁移句法**：

- 我说好。
- 他没回。
- 我又发了一遍。
- 这次系统没有报错。
- 三分钟后，钱到了。
- 他把群名改了。

**误区**：

- 不要每三五句话就用 `---`。普通换场只换段。
- 不要把每个场景写成摘要。关键场景至少要能单独读出重量。
- 不要连续解释人物心理。让短句自己产生压力。

## 四、数字是度量衡，不是装饰

**作用**：用数字替代形容词，让抽象关系变成可以称重的东西。

数字有四种用途：

- **贫富对照**：一个小数字和一个大数字放在一起。
- **记忆精度**：越小越准的数字，说明叙述者没有忘。
- **流程真实感**：限额、页数、时间、次数、排队人数。
- **荒诞感**：巨大资源服务于一个很小目的。

**可迁移句法**：

- 那份合同四十七页，他只改了一个字。
- 我们融资两千万美元的时候，前台的绿植还是租的，一个月六百。
- 他让我等十分钟。我看了表，是二十六分钟。
- 一张卡一天只能转一百万。那天用了五张。

**误区**：

- "很多""巨大""很久"都要优先换成真实数字。
- 记不清就写记不清，不要补假精确。
- 金额后面不要接感慨。数字自己会说话。

## 五、物件负责记忆

**作用**：让一个小东西替作者完成情绪总结。

物件要普通、可触摸、能回收。第一次出现时必须只是生活物，不能自带象征说明。第二次回来时，环境或关系已经变了。最后一次出现时，读者知道它变重了，但作者不说。

**可选物件**：

- 私人关系：旧照片、钥匙、戒指、车票、杯子、没拆的药。
- 创业：工牌、门禁卡、旧电脑、第一张发票、会议牌、合同红线。
- 财富：银行卡、账单、限额短信、收据、保险柜编号。
- 技术：API 日志、验证码、链上 hash、系统提醒、失败重试记录。

**可迁移句法**：

- 那张门禁卡我一直没退。后来公司搬了三次，卡上的楼层还是十九层。
- 他送我的那支笔没什么特别，笔帽上有一道划痕。签解散协议那天，我用的还是它。
- 日程提醒是去年设的。弹出来的时候，项目已经停了四个月。

**误区**：

- 不要写"这支笔象征着我们的开始"。
- 不要硬塞一个物件。素材里没有能回来的东西，就用流程或数字回环。

## 六、沉默和留白

**作用**：把最关键的信息悬住，让读者自己补。

沉默有三类：

- **主动沉默**：知道，但不说。
- **被动沉默**：想说，但说不出来。
- **永久沉默**：后来再也无法确认。

留白不是缺资料。事实边界要清楚，意义可以不解释。叙述者不知道的事，就停在不知道那里。

**可迁移句法**：

- 我没有问。
- 他看了一眼手机，没有回。
- 我知道那句话还有后半句。他没说。
- 电话那边有人在喊他的名字。我听见了，但没听清是谁。
- 我后来查过记录。记录只到这里。

**误区**：

- 不要在沉默后解释"其实他当时很痛苦"。
- 不要用省略号制造廉价停顿。
- 不要故意缺少关键事实冒充高级。读者必须知道发生了什么，只是不知道它意味着什么。

## 七、旁观者和系统是最冷的镜子

**作用**：让不相干的人或机器照见主线，避免作者自己抒情。

旁观者可以是服务员、司机、保安、助理、财务、医生、前台、孩子、会议志愿者。他们不理解主线，只执行自己的工作。正因为不理解，文本才冷。

系统可以是支付限额、链上记录、AI 回复、医院流程、酒店登记、航班配平、风控提示、CRM、日程提醒。系统不懂人，只保留记录。

**可迁移句法**：

- 财务问这笔钱走什么科目。我说市场费用。
- 前台说，访客贴纸要贴在胸前。我贴了。那天我是公司创始人。
- 系统显示交易成功。备注栏空着。
- 保安看了我的身份证，又看了屏幕，说名单里没有。

**误区**：

- 不要让旁观者替你说主旨。
- 不要把系统写成科普段落。
- 不要让机器懂爱情、懂命运。机器只给结果。

## 八、财富宣言：反体面判断

**作用**：从故事里突然切出一句硬判断，让文本带有孙宇晨早期财富课的攻击性。

宣言句不能密集。它像钉子，一篇长文三到五颗就够。每颗钉子前面必须有具体事实，后面最好有一个结果或动作。

**结构**：

1. 先写一个具体场景。
2. 再给出违反体面话的判断。
3. 用经历、数字或失败压住它。
4. 不劝人，不鸡汤。

**可迁移句法**：

- 很多人说选择比努力重要。那是因为他们还没有见过选择的价格。
- 年轻的时候，人最容易把尊严当资产。后来我发现，它更像负债。
- 所谓自由，不是你想做什么都可以做。是有些电话你可以不接。
- 世界不是奖励正确的人。世界奖励能承担后果的人。

**误区**：

- 不要堆"认知升级、底层逻辑、时代红利"。
- 不要写成励志演讲。
- 不要脱离场景空喊价值观。

## 九、全球漂浮感

**作用**：用地点、距离、温差和行程制造一种没有根的流动状态。

孙学体里的地点不是风景明信片。地点要和流程相连：机场、酒店、会议、诊所、交易所、路演、签证、时差、落地时间。越能移动，越显出某些东西留不住。

**可迁移句法**：

- 北京零下六度，新加坡二十九度，飞六个小时。PPT 没改完。
- 他在迪拜发来语音，我这边是凌晨。背景里有人说英文。
- 酒店窗外就是海，但会议室没有窗。
- 航班落地的时候，群里已经有四十三条未读。

**误区**：

- 不要写"异国风情"。
- 不要堆城市名。每个地点都要改变人物关系或事件压力。
- 不要把全球化写成成功学。它也可以是漂泊、失真和延迟。

## 十、人物神话和自我暴露

**作用**：让叙述者既强大又不体面，既能动用资源又有明显软肋。

孙学体的人物不是完美主角。他可以承认算计、虚荣、恐惧、犹豫、交易化思维。关键是承认得平静，不忏悔，不求原谅。

**可迁移句法**：

- 我不是大方。我只是怕他走。
- 我当时以为这是效率。后来发现是懒得面对。
- 我没有相信他。我只是选择先不拆穿。
- 那天我算过，损失不大。让我不舒服的是，我第一反应居然是算。

**误区**：

- 不要把自我暴露写成煽情忏悔。
- 不要把主角写成全知全能。
- 不要怕主角不讨喜。孙学体的可信度往往来自不讨喜。

## 十一、蒙太奇和回环

**作用**：用几个相隔很远的画面互相照亮，而不是按流水账讲完。

时间跳切必须有锚点：年份、地点、物件、数字、称谓、系统记录。跳切不是省略困难部分。每个被选中的场景都要足够厚。

**常用结构**：

1. 开头放最刺眼的一刻。
2. 回到很早以前的一个小物件或小失败。
3. 中段让同一物件、数字或句式反复出现。
4. 转折处打破重复。
5. 结尾让开头的东西回来，但不解释。

**可迁移句法**：

- 七年前，我为了省八十块，坐了一夜硬座。
- 七年后，同一条线路，我包了整节车厢。
- 车窗外还是那几盏灯。
- 我没有看。

**误区**：

- 不要把 `---` 当普通场景分隔符。
- 不要为了回环硬扣题。回来的东西必须真的在前文出现过。
- 不要结尾升华。结尾只给画面。

## 十二、称谓变化

**作用**：用称呼变化记录关系变化。

称谓比心理描写更准。全名、昵称、职务、代词、旧称呼、备注名，都可以成为关系温度计。

**可迁移句法**：

- 起初我叫他王总。
- 后来叫老王。
- 签完那天，我在通讯录里把备注改回了王建国。

**误区**：

- 不要解释"称谓变化说明我们疏远了"。
- 不要强行设计称呼。它必须来自关系本身。

## 十三、反高潮

**作用**：把大事件落到小动作上，制造残酷的轻。

越大的钱、越大的排场、越大的失败，越应该落在普通动作上。转账之后是验证码，分手之后是心跳，融资之后是前台绿植，发布会之后是撤掉桌牌。

**可迁移句法**：

- 发布会结束后，最先撤掉的是他的桌牌。
- 钱到账那天，办公室空调坏了。
- 项目停掉以后，服务器又扣了一个月费用。
- 他走之后，我才发现他的杯子还在洗碗机里。

**误区**：

- 不要故意抖机灵。
- 不要把小动作写成段子。
- 不要解释"这就是人生的荒诞"。

## 十四、不同题材的迁移方案

**创业故事**：

- 开头用早期小成本 vs 后来大规模。
- 物件选门禁卡、旧电脑、第一张发票、会议牌。
- 系统选融资流程、财务审批、服务器账单、HR 名单。
- 命题可以是：公司变大后，最先消失的是具体的人。

**财富观点文**：

- 开头用一个小犹豫 vs 一个大决策。
- 中段穿插反体面判断。
- 数字必须来自真实经历或公开事实。
- 命题可以是：财富不是答案，是让问题暴露得更快。

**技术/AI/区块链文章**：

- 技术不要科普化，要叙事化。
- 让系统在关键处给出冷结果。
- 用链上记录、API、日志、风控、模型回复替代情绪解释。
- 命题可以是：机器不理解人，但它有时比人诚实。

**人物 IP 稿**：

- 公开头衔和私人动作并置。
- 不要写完美人设，写代价、弱点和荒谬。
- 地点用全球流动制造漂浮感。
- 命题可以是：一个人被时代放大后，连缺点也变成了公共资产。

**情感叙事**：

- 少写爱恨，多写流程和物件。
- 让称谓变化承担关系变化。
- 让沉默发生在电话、车里、酒店、医院、账单之后。
- 命题可以是：真正结束的不是关系，是某个动作再也没人教你怎么做。

## 十五、终稿自检

交付前逐项删改：

- 有无直接情绪词。
- 有无假精确数字。
- 有无解释象征意义。
- 有无空泛鸡汤判断。
- 有无过密的金句。
- 场景是否只剩摘要。
- 技术是否变成科普。
- 金钱是否变成炫耀。
- 全球地点是否只是摆设。
- 结尾是否说理。
- 有没有一个小物件、一个系统记录或一个数字真正回来。

最后一条最重要：读者应该先看到人和事，后感觉到技法。只要读者先看到"这里在用孙学"，这段就应该降温。
